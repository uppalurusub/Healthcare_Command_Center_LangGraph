Recommended Agent Usage
Agent	Best Use Case	Analytics Enabled
supervisor	Executive dashboards, cross-functional hospital operations	Admissions, Bed Management, ICU, Finance
admissions	Patient inflow, admissions trends, forecasting	Admissions only
bed_management	Bed occupancy, discharge planning, resource allocation	Bed Management only
icu	Critical care monitoring, ICU utilization, risk analysis	ICU only
finance	Revenue, insurance claims, billing, financial KPIs	Finance only

These examples provide realistic payloads for testing your FastAPI endpoints and exercising each specialized agent independently as well as the supervisor's multi-agent orchestration.
